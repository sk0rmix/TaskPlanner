# Модуль Data

## Назначение

Модуль отвечает за хранение моделей данных приложения.

## Входные данные

* данные задач;
* параметры задачи.

## Выходные данные

* список задач;
* объекты TaskModel.

## Взаимодействие

Используется модулем Logic для доступа к данным.

## Пример использования

```csharp
TaskRepository repository = new TaskRepository();
repository.Add(task);
```
