# Модуль Logic

## Назначение

Реализация бизнес логики приложения.

## Входные данные

* данные задач;
* команды пользователя.

## Выходные данные

* обновленные данные задач.

## Взаимодействие

Использует модуль Data и взаимодействует с UI.

## Пример использования

```csharp
manager.CreateTask("Новая задача", "Описание");
```
