# Task Planner

## Цель проекта

Разработка учебного WPF-приложения «Task Planner» для управления задачами с использованием принципов модульной архитектуры и шаблона MVVM.

Основные возможности приложения:

- создание задач;
- просмотр списка задач;
- изменение статуса выполнения;
- хранение описания задач;
- установка даты выполнения;
- экспорт списка задач в JSON.
